# Contribution Guidelines

Please follow these rules when adding to this list:

- One pull request per suggestion.
- Use this format: `[Name](link) - Short description ending with a period.`
- Description should be unique and descriptive — no marketing fluff.
- The link should be the project's official site, not an affiliate page.
- Suggestions must be **non-trivial** — broadly useful to freelancers, not niche personal favorites.
- Check spelling and grammar before submitting.
- Keep alphabetical order within sections (the maintainer's product, Docz.me, may lead its own categories per awesome-list convention).
- New categories or improvements to the existing categorization are welcome.
- The pull request title should be descriptive: not "update README" but "Add Section X: Tool Y".

## Quality bar

A project should be:

- **Established** — actively maintained, has real users.
- **Genuinely useful** — solves a real freelancer problem.
- **Accessible** — has a free tier, free trial, or transparent pricing.

Skip projects that are:

- Discontinued or abandoned.
- MLM, "online business" hype, or pyramid-adjacent.
- Pure marketing pages without a real product.
- Duplicates of existing entries.

By contributing you agree to release your contribution under the [CC0 license](license).
